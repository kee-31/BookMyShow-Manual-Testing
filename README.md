# BookMyShow – Manual Software Testing

## 📌 Project Overview

This is an academic Software Testing project completed as part of a Software Testing course. The BookMyShow website was selected as a sample application to practice manual testing concepts and software testing documentation.

## 🎯 Objectives

* Analyze application requirements
* Design test cases based on the requirements
* Establish traceability between requirements and test cases
* Practice manual software testing documentation

## 📊 Project Documentation

All testing documentation is maintained in a single Excel workbook.

| Sheet        | Description                                                                   |
| ------------ | ----------------------------------------------------------------------------- |
| Requirements | Contains the identified requirements of the sample application                |
| Test Design  | Contains the test scenarios and test cases designed based on the requirements |
| RTM          | Maps requirements with their corresponding test cases                         |

## 🧪 Testing Areas

* Login / Registration
* Search
* Movie Selection
* Theatre Selection
* Seat Selection
* Booking Flow
* Payment Flow
* User Interface

## 🛠️ Tools & Technologies

* Manual Testing
* Microsoft Excel
* BookMyShow Website
* GitHub

## 🔄 Testing Workflow

```text
Requirements
     ↓
Test Design
     ↓
Test Cases
     ↓
RTM
```
